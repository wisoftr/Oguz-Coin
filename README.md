## 🌐 About OGZ Coin

OGZ Coin is a BEP-20 digital asset built on the Binance Smart Chain (BSC).  
Its purpose is to offer a fast, transparent and low-cost value transfer system for all global Turkic communities.

Inspired by the legacy of **Oğuz Kağan**, OGZ represents unity, cultural heritage and a modern Web3 economic vision.
